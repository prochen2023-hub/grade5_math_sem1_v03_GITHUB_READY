**12站冒險＋ABCD全開＋期中期末魔王考版**。純前端網站，可直接部署到 GitHub Pages。

## v0.8 重點

- 學習旅程由 10 個數學章節＋2 個獨立檢核點組成，共 **12 站**。
- 第 1～5 章後插入 **第 6 站：期中魔王檢核**。
- 第 6～10 章在旅程中編為第 7～11 站，第 10 章後插入 **第 12 站：期末魔王檢核**。
- A / B / C / D 四級五題挑戰 **全部可直接預覽與切換**，不再上鎖。
- 挑戰關卡標題改用高對比藍紫漸層，文字改為更大的淡色字，提升閱讀辨識。
- 每一級仍固定 5 題、附圖像提示；答對 3 題就算過關，答錯不扣星、不扣 XP。

## 期中／期末模擬考

模擬考採學校定期評量的混合題型節奏，但所有題目均為本專案重新設計：

| 題型 | 配分 |
|---|---:|
| 選擇題 | 20 分 |
| 填充題 | 20 分 |
| 計算題 | 24 分 |
| 應用題 | 36 分 |
| **總分** | **100 分** |

- 期中範圍：第 1～5 單元。
- 期末範圍：第 6～10 單元。
- 期中與期末各有 **A、B 兩卷**，兩卷題目不同、獨立記分。
- 每卷 15 題，**40 分鐘**倒數。
- 剩 10、5、1 分鐘與時間到會響鈴。
- 計算題、應用題附草稿／列式區與最後答案欄。
- 題目依內容搭配位值表、數線、分數圖、幾何圖、對稱圖、面積圖與立體圖。
- 成績會保存「本次分數、最佳分數、挑戰次數」。
- 80 分以上取得一顆 **魔王星**；90 分以上顯示 **金冠魔王**。
- A、B 卷分開給 XP；提高最佳成績時只補發尚未拿到的獎勵差額，不倒扣。
