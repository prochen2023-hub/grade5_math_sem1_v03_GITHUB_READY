# 國小五年級上學期數學｜v0.3.1

**逐章教學深化版（v0.3.1 修正版）**。這是一個可直接部署到 GitHub Pages 的純前端互動數學網站。v0.3 的核心不是再堆更多題目，而是把每章變成一條孩子能自己走完的學習路徑：**先診斷 → 看懂圖 → 跟著做 → 找錯因 → 解生活題 → 修錯 → 挑戰**。


## v0.3.1 修正重點

- 修復 v0.3 遺漏 `mainLab()` / `miniLab()` 路由函式，造成章節主內容空白、按鈕無法作用的重大問題。
- 10 章互動圖與小實驗全部重新建立對應。
- 新增 `scripts/smoke_test.js`：會實際執行 `app.js` 並逐章確認主內容、生活任務、錯誤診療室、Boss 題與 10 題練習均成功渲染。
- GitHub Actions 部署前現在同時執行 Python 資料驗證與 Node 互動渲染 smoke test。
- 新增啟動錯誤畫面；未來即使資料或程式載入失敗，也不再只留下空白頁。
- 靜態資源加入 `?v=0.3.1`，降低 GitHub Pages/瀏覽器沿用舊版 JS 快取的機率。

## v0.3 核心改動

- 10 章全部加入 **10 秒起點快問**，先確認孩子目前怎麼想，不計分。
- 10 章全部加入 **逐步例題**，每一步都有理由與合理性檢查。
- 10 章全部加入 **錯誤診療室**，練習辨認「錯在哪個觀念」，不是只公布答案。
- 10 章全部加入 **Boss 生活挑戰題**，首次答對 `+12 XP`。
- 練習題擴充為每章 10 題，共 **100 題**，以購物、交通、料理、校園、運動、空間、包裝等生活情境為主。
- 每題加入難度、技能、提示與錯誤提醒。
- 新增 **錯題袋**：答錯的練習會自動標記為待修；修正答對後會累積「錯題修復」紀錄。
- 新增「錯題修復師」與「Boss 挑戰者」成就。
- 版主進度頁新增待修錯題、已修復錯題與 Boss 完成數。
- 延續 v0.2 的 XP、等級、星星、連勝、章節徽章、今日挑戰與 GitHub Pages 自動部署。

## 每章學習流程

1. **10 秒起點快問**：先想一次，不計分、不製造壓力。
2. **生活故事**：知道這個概念在什麼情境會用到。
3. **互動圖**：先用圖像與操作看懂數學結構。
4. **一句人話**：把規則說成孩子能記住的語句。
5. **逐步例題**：看清楚每一步「為什麼這樣做」。
6. **小實驗**：換一個角度再次驗證。
7. **錯誤診療室**：辨認常見錯法及其原因。
8. **生活任務**：完成章節主關卡，解鎖徽章與第 1 顆星。
9. **Boss 題**：在精熟區做一題較完整的生活活用挑戰。
10. **10 題分層練習＋錯題修復**：可篩選全部、生活題或待修錯題。

## 10 個核心單元

1. 多位小數與加減
2. 因數與公因數
3. 倍數與公倍數
4. 擴分、約分與通分
5. 多邊形與扇形
6. 異分母分數的加減
7. 線對稱圖形
8. 整數四則運算
9. 面積：平行四邊形、三角形、梯形
10. 柱體、錐體和球

目前採「跨版本共通概念骨架＋常見五上順序」。後續可依康軒、翰林、南一實際版本建立章節對照與切換。

## 獎勵規則

- 章節生活任務首次答對：`+25 XP`、解鎖章節徽章、取得第 1 顆星。
- Boss 題首次答對：`+12 XP`。
- 練習題首次答對：`+8 XP`。
- 連續答對 3 題以上：每次另有少量連勝 XP。
- 每章練習答對至少 3 題：2 星；至少 6 題：3 星。
- 每 100 XP 升 1 級。
- 答錯**不倒扣 XP**；錯題進入待修清單，之後答對會計入錯題修復成就。

## 本機啟動

Windows 可直接雙擊 `START_LOCAL.bat`，或在專案根目錄執行：

```bash
python -m http.server 8000
```

再開啟 `http://localhost:8000`。不要直接用 `file://`，因為網站會用 `fetch()` 讀取 JSON。

## GitHub Pages 部署

本 repo 已包含 `.github/workflows/pages.yml`：

1. 建立 GitHub repository。
2. 將本資料夾內容放在 repository root。
3. push 到 `main` branch。
4. GitHub → **Settings → Pages → Build and deployment → Source** 選 **GitHub Actions**。
5. workflow 完成後即可取得 Pages 網址。

詳細步驟見 [`docs/GITHUB_PAGES.md`](docs/GITHUB_PAGES.md)。部署 workflow 會先執行 `python scripts/validate_project.py`，再執行 `node scripts/smoke_test.js`；兩者都通過才發布。

## 進度與隱私

目前帳號及學習進度只存在瀏覽器 `localStorage`。`admin-progress.html` 只能讀取同一台瀏覽器曾使用過的帳號，GitHub 不會收到學生進度。v0.1 / v0.2 的 `g5m1` 進度可繼續讀取；v0.3 新欄位會自動補預設值。
