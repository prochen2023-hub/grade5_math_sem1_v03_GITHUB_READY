## 前五章深化

### 1. 多位小數與加減

- 位值由 **十萬位一路到萬分位**。
- 可逐格修改位值，並有 `305,042.7086` 的學生填格練習。
- 小數比較：末尾補 0、逐位比較。
- 多位小數加減：小數點／位值對齊，缺位補 0。
- 四捨五入：用數線呈現左右候選概數與中點。
- 價格、重量、距離、氣溫等生活題。

### 2. 因數與公因數

- 從以前學過的 `乘法 ↔ 除法互逆` 接到因數與倍數。
- 明確定義「整除＝餘數 0」。
- 用乘法配對列出所有因數，保留「最細拆到 1／完全不拆就是本身」模型。
- 公因數、最大公因數與分裝／裁切／平均分組生活題。

### 3. 倍數與公倍數

- 和因數一起解釋成「整除關係的兩面」。
- 數線顯示固定步長與共同落點。
- 強調倍數、公倍數可無限延伸，因此**沒有最大倍數／最大公倍數**。
- 跑步與操場模型可調每圈時間與跑道長度，計算第一次同時回起點、各跑幾圈與距離。

### 4. 擴分、約分與通分

- 直接從字面解釋：`擴＝擴大份數`、`約＝約簡`、`通＝通到共同刻度`。
- 與倍數、公因數、公倍數連結，不要求死背。
- 圓餅圖呈現 `1/2 = 2/4 = 4/8`。
- 同分母與同分子的快速比較規則。
- **擴分、約分、通分各至少 2 題計算＋2 題生活素養題**。

### 5. 多邊形與扇形

- 3～10 邊形可互動切換；正 n 邊形另行說明「邊等長＋角相等」。
- 三角形成立條件可用三邊滑桿測試「兩邊和大於第三邊」。
- 多邊形內角和以 `n−2` 個三角形的拆解圖呈現。
- 正三角形、等腰三角形角度互動。
- 平行四邊形：**對角相等、鄰角互補**。
- 梯形：一般梯形不誤教「對角相等」；正確呈現同一腰兩內角互補，並另列等腰梯形性質。
- 圓心角、弧、弧長、扇形保留互動圖。
- **12 組角度大雜燴圖庫**：對頂角、平角、三角形、上下交疊三角形、星型／飛鏢型、平行四邊形、梯形。
