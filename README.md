# 國小五年級上學期數學｜v0.4.0

**圖解互動深化版**。這是一個可直接部署到 GitHub Pages 的純前端互動數學網站。v0.4 的設計重點從「章節有內容」再往前一步，改成：**先把關係畫清楚，再讓孩子拖動、比較、說出誰和誰的關係，最後才進入公式與生活題。**

## v0.4 核心改動

### 1. 因數與公因數
- 用「零用錢／物品分裝」取代單純列因數。
- 明確呈現兩個極端：最細拆成每份 1，以及完全不拆就是本身。
- 可拖動總數，立即看到所有因數配對。
- 公因數改成兩筆總數的「共同分法」，可拖動兩個數比較最大公因數。

### 2. 倍數與公倍數
- 新增真正的數線落點圖：兩個不同步長從 0 出發，共同落點高亮。
- 同時標示第一個與第二個共同落點。
- 新增操場跑步模型：可設定兩人每圈時間與跑道一圈距離，算出再次同時回到起點的時間、圈數與距離。

### 3. 多邊形、圓與扇形
- 明確區分「邊長」與「周長」。
- 可切換 3～8 邊形，並切換正多邊形／不規則多邊形。
- 正多邊形顯示 `邊數 × 邊長`；不規則多邊形改為逐邊相加。
- 明確說明圓沒有多邊形那種直線「邊長」，一整圈叫圓周長。
- 扇形互動可調圓心角與半徑，圖中同時標示圓心、兩條半徑、弧、弧長與扇形區域。
- 強調扇形必須由「兩條半徑＋中間的一段弧」圍成，角的頂點必須在圓心。

### 4. 線對稱
- 以鏡子／鏡面作為核心模型。
- 可拖動 A 點離對稱軸的距離與上下位置，A′ 自動保持相同垂直距離。
- 圖中標示直角，強調 AA′ 與對稱軸垂直。
- 可切換正三角形、正方形、正五邊形、正六邊形與圓，認識對稱軸數量。
- 特別提醒：正 n 邊形有 n 條對稱軸，但一般 n 邊形不一定對稱。

### 5. 面積
- 可切換平行四邊形、三角形、梯形。
- 可拖動底、高與梯形上底。
- 平行四邊形與鈍角三角形刻意畫出「底所在直線的延長線」，讓孩子看到垂足可以在圖形外。
- 明確標示：三角形的高是「頂點到底邊所在直線的垂直距離」；梯形的高是「兩條平行底邊之間的垂直距離」。
- 斜邊／斜腰不是高，除非它真的和底垂直。

### 6. 柱體、錐體和球
- 原本的平面符號改成 SVG 立體透視圖。
- 可切換角柱、圓柱、角錐、圓錐、球。
- 可拖動高度、底面大小與觀看角度。
- 每一種立體同步列出底面、側面、稜與頂點特徵。
- 球特別強調只有曲面，沒有平面底面、稜與頂點。

## 其他章節的平衡調整

v0.4 也同步調整多位小數、擴約分與通分、異分母分數、四則運算：加大圖解與文字、增加圖文間距，讓全部 10 章維持同一套「圖像 → 人話 → 逐步例題 → 小實驗 → 錯誤診療 → 生活任務 → Boss → 分層練習」節奏。

## 題庫與獎勵

- 10 章，共 100 題分層練習。
- 題目以生活情境為主，生活題以 🏙️ 標示。
- XP、等級、1～3 星、連勝、章節徽章、Boss、錯題袋與錯題修復保留。
- 答錯不扣分；修正答對會累積「錯題修復」成就。

## 本機執行

Windows 可直接執行 `START_LOCAL.bat`，或在 repository root 執行：

```bash
python -m http.server 8000
```

然後用瀏覽器開啟 `http://localhost:8000/`。

## 發佈到 GitHub Pages

1. 把本 ZIP 的內容直接放在 repository root，不要再多包一層 `web/`。
2. Push 到 `main`。
3. Repository → **Settings → Pages**。
4. Source 選 **GitHub Actions**。
5. workflow 會先跑內容驗證、10 章渲染 smoke test、v0.4 圖解邏輯測試，再部署。

詳細步驟見 `docs/GITHUB_PAGES.md`。

## QA

打包前應通過：

```bash
python scripts/validate_project.py
node scripts/smoke_test.js
node scripts/interaction_test.js
```

其中 `interaction_test.js` 會直接檢查重要圖解計算，例如：4 與 6 的第一、第二共同落點、操場再次同時回起點、正多邊形周長、90° 弧占全圓 1/4、正五邊形對稱軸、三角形底邊延長線、梯形高與五種立體圖。

## 進度資料

目前帳號與學習進度只存在瀏覽器 `localStorage`，namespace 沿用 `g5m1`，所以舊版進度可以繼續讀取。`admin-progress.html` 只能看到同一台瀏覽器使用過的帳號；GitHub Pages 不會收到學生個資或進度。
