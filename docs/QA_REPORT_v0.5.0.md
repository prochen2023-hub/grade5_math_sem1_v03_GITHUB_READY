# QA Report｜v0.5.0 前五章深度互動版

## 本版針對的問題

- 首頁「今天任務」與「整學期 10 章」視覺與功能混在一起。
- 10 個核心關卡與四張功能 Icon 不可點。
- 今天任務實際載入完整第一章，沒有「一天只學一件事」的節奏。
- 內文字級與精熟區入口過小。
- 前五章概念深度不足。

## 修正結果

- Today mode 與 chapter mode 分離。
- 10 個章節地圖與 4 張功能卡改成真正的 `<a>` 連結。
- 前五章新增 30 張單一觀念卡。
- 全站題庫 148 題，前五章 98 題。
- 第 4 章擴／約／通各有至少 2 題計算＋2 題生活題。
- 第 5 章有 12 張複合角度圖，題庫中有 10 題以上複合角度組合題。
- 一般梯形的角度性質已採正確敘述，與平行四邊形分開。
- v0.5 深度視覺在完整章節使用獨立 control id，避免和舊版主互動圖重複 ID 導致滑桿操作錯誤。

## 自動測試

- `python scripts/validate_project.py`：章節、題庫、答案、連結、today card schema。
- `node scripts/smoke_test.js`：10 章完整渲染；Today mode 確認不包含完整章節區塊。
- `node scripts/interaction_test.js`：既有圖解數學邏輯回歸測試。
- `python scripts/v05_content_test.py`：前五章卡片數、題型數、首頁可點入口、複合角度與重複 ID 回歸檢查。

## 瀏覽器環境說明

本工作環境的 Chromium headless 會因系統 D-Bus／沙箱環境無法正常完成本機頁面導覽，因此本版不把 Chromium 點擊測試宣稱為已通過；改採 Node DOM smoke test、內容驗證與數學邏輯回歸測試。部署後仍建議在桌機與手機各做一次人工點擊驗收。
