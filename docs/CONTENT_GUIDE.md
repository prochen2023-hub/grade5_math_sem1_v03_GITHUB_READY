# Content Guide｜v0.5

## 核心原則

1. **今天任務一次只教一個核心觀念。** 每張卡要有：`title / definition / focus / visual / q / options / answer / explain`。
2. **完整章節可很完整，但每張觀念卡不可同時塞多個新定義。**
3. 先圖解、再人話、再算式、最後生活應用。
4. 名詞必須說清楚「誰和誰的關係」，例如整除、對角、鄰角、圓心角、弧。
5. 視覺元件若有滑桿，改變數值後文字與圖必須同步更新。
6. 不用錯誤的快速口訣取代數學性質。一般梯形不可說成「對角相等」。

## 題庫

- 每章至少 10 題；前五章 v0.5 有更高最低數量。
- 生活題使用 `type: life`。
- 第 4 章擴分、約分、通分：各至少 2 題計算＋2 題生活題。
- 第 5 章複合角度（含星型／交疊／飛鏢型）至少 10 題。
- 每題都要有 `hint` 與 `wrong_tip`，答錯時先提示錯因，不直接只給答案。

## Today cards

`units.json` 的 `today_lessons` 是 focused mode 的資料來源。前五章目前依序 5、5、5、6、9 張。首頁「開始今天任務」進入這個模式；側欄章節與學期地圖則進入完整章節模式。
