# Content Guide｜v0.6

## 核心原則

1. **首頁不展示整學期壓力。** 第一眼只放今天任務、目前獎勵與繼續學習。
2. **今天任務一次只教一個核心觀念。** 每張卡含 `title / definition / focus / visual / q / options / answer / explain`。
3. **完整章節每個重要框格盡量可朗讀。** 定義與題目優先；喇叭放在框格起始處。
4. 先圖解、再人話、再算式、最後生活應用。
5. 名詞要說清楚「誰和誰的關係」，例如高、對稱點、整除、圓心角、弧。
6. 互動圖改數值後，圖與文字必須同步。
7. 不用錯誤口訣取代性質；一般梯形不可教成「對角相等」。
8. 獎勵只回饋進步：答錯不扣星、不扣 XP。

## 題庫

- 每章至少 16 題；v0.6 第 6～10 章各 18 題。
- 每章至少 5 題生活題。
- 每題有 `hint` 與 `wrong_tip`。
- 第 4 章擴分、約分、通分各至少 2 題計算＋2 題生活題。
- 第 5 章複合角度至少 10 題。

## Today cards

全 10 章都有 `today_lessons`。首頁「開始今天任務」進入 focused mode；「完整學習」才進完整章節。
